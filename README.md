# Engineering, AI & Quantitative Research Portfolio

Selected projects at the intersection of **mechanical engineering, software prototyping, engineering decision systems, and derivatives risk**.

This repository contains project case studies, representative documentation, and selected CAD drawings. Not all showcased applications have publicly released source code. Each case study distinguishes what is visible in its demonstration from what remains to be verified.

## Featured projects

### 01 · [Prompt-to-CAD — AI-Assisted Mechanical Design](prompt-to-cad/README.md)

**Natural-language design inputs → interactive 3D mechanisms → iterative parameter refinement.** A recorded browser demo showcases a planetary gearset, geometry controls, inspection modes, a visible specification, and a rack-and-pinion example.

[Technical case study](prompt-to-cad/README.md) · [One-page project overview](prompt-to-cad/index.html) · [CV summary](prompt-to-cad/PORTFOLIO_ENTRY.md)

### 02 · [MatSelect AI — Engineering Material Selection](matselect-ai/README.md)

**Engineering constraints → ranked materials → explainable trade-offs.** A guided material-selection prototype with mechanical, environmental, manufacturing, cost, and sustainability inputs. The recorded demo shows comparative results, radar-chart visualization, material rationale, and limitations.

[Project case study](matselect-ai/README.md) · [CV summary](matselect-ai/PORTFOLIO_ENTRY.md)

### 03 · [HedgePilotX — Adaptive Options Hedging Research](hedgepilotx/README.md)

**Dynamic hedging under a risk budget and market frictions.** A simulated quantitative research terminal exploring how rebalancing controllers trade off hedging risk, costs, robustness, and validation discipline. The video demonstrates controller comparisons, path replay, stress scenarios, held-out evaluation, and saved study records.

[Research case study](hedgepilotx/README.md) · [CV summary](hedgepilotx/PORTFOLIO_ENTRY.md)

### 04 · [Hydraulic Pump Assembly](hydraulic-pump/)

SolidWorks assembly and mechanical drawing documentation, including an exploded view.

## Repository scope

**The app case studies are documentation, not reproducible code releases.** Original executable app repositories, validation test suites, and uploaded MP4 demo assets are not currently part of this repository. The demonstrations were reviewed when preparing the case studies; quantitative performance, CAD accuracy, and material recommendations should not be treated as independently verified.

For the best overview of each prototype, open its case study above. Engineering and financial decisions require their own independent verification.
